# Weapon models

- `fps/`: first-person arms with weapons, see `fps/CREDITS.md`.
- `world/`: realistic weapon models for pickups and characters, see `world/CREDITS.md`.
- `casings/`: spent cartridge cases, made for this project by `casings/source/casings.py` (procedural), CC0 1.0.
- `molotov/`: the incendiary bottle (thrown model, label, rag and glass textures), made for this project by `molotov/source/*.py` (procedural Blender scripts), CC0 1.0. The label brand is made up.
