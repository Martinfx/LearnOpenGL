# PBR texture sets (Poly Haven)

All sets are from [Poly Haven](https://polyhaven.com), license **CC0 1.0** (public domain),
https://polyhaven.com/license. 2K JPG, OpenGL normal maps (+Y up). Each folder holds
`albedo.jpg` (sRGB), `normal.jpg`, `roughness.jpg`, `ao.jpg`, `height.jpg` and, for metals, `metallic.jpg`.
A ready material for each set is in `assets/materials/pbr/<name>.material`.
