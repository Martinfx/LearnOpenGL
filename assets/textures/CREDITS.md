# Textures

`concrete*.png`, `bricks*.png`, `metal_plate*.png` (albedo, normal, roughness), `prototype_grid.png`: generated for this
project by `tools/make_textures.py` (procedural, tileable). Public domain (CC0).

`particles/*.png` (smoke, fire, explosion, dust, muzzle flash, spark, debris, raindrop): rendered for this project by
`particles/source/particles.py` (Blender Cycles volumes + procedural), CC0. The debris chips are textured with the
Poly Haven scans `pbr/concrete_wall_007` and `pbr/rough_wood` (CC0, polyhaven.com).
